# منظومة إسناد المتكاملة | Esnad Government Services Platform
## نظام إدارة مكاتب الخدمات الحكومية متعددة الفروع

منظومة ويب متقدمة موجهة للإنتاج (Production-Ready) مبنية وفق أحدث معايير الأمان المالي، وهندسة البرمجيات المقاومة للأخطاء (Fault-Tolerant Financial Ledger Architecture)، لتشغيل وإدارة مكاتب الخدمات الحكومية متعددة الفروع مع استقلالية مالية كاملة لكل فرع.

---

### المميزات الأساسية

1. **الاستقلالية المالية للفروع (Branch Financial Isolation)**:
   - لكل فرع درج نقدي (Cash Drawer) ودفتر أستاذ مالي (Financial Ledger) مستقل تماماً.
   - دعم التحويل الذري بين الفروع (Atomic Inter-Branch Transfers).
   - انتقال المعاملات بين فروع الإنشاء والتنفيذ والتسليم مع تتبع سجل التدقيق (Audit Trail).

2. **محرك الخدمات المتطور (Configurable Services Engine)**:
   - دعم بطاقة الرقم القومي بسرعاتها (عادي، مستعجل، فوري، سوبر فوري) والباركود ومصدر الاستمارة.
   - دعم جوازات السفر، شهادات الميلاد، شهادات الوفاة، مع إمكانية إضافة خدمات جديدة بحقول مخصصة ديناميكية دون تعديل الكود.

3. **إدارة التحصيل المالي والدفعات الجزئية (Multi-Transaction Partial Payments)**:
   - فصل دقيق بين النقد (Cash) والمدفوعات الإلكترونية (InstaPay / المحافظ الإلكترونية).
   - النقد فقط هو ما يغذي رصيد الدرج، بينما يتم تقييد الإلكتروني محاسبياً دون خلط.
   - دعم الدفعات المتعددة وتتبع من قام بكل دفعة وفي أي فرع.

4. **إدارة الموزعين والمكاتب الخارجية (Distributors & External Processing Offices)**:
   - الموزعون: تتبع المستحقات والتوريدات النقدية مع تسوية جزئية وتحديث فوري للأرصدة.
   - المكاتب الخارجية: تسجيل تكلفة التنفيذ كمصروف مرتبط بالعملية وحساب هامش الربح بدقة.

5. **الإغلاق والتسوية اليومية (Atomic Daily Closings)**:
   - تصفير الرصيد التشغيلي لبدء يوم جديد مع الحفاظ المطلق على كامل السجلات التاريخية.
   - حماية صارمة تمنع إغلاق نفس اليوم مرتين لنفس الفرع.

6. **أمان العمليات ومنع التكرار (Idempotency & Concurrency Safeguards)**:
   - توليد `Idempotency Keys` فريدة لكل حركة مالية لمنع التكرار الناتج عن النقر المزدوج أو تقلبات الاتصال.
   - قفل الحالة (UI Disabled States & Atomic Execution) ومعالجة حالات انقطاع واستعادة الاتصال.
